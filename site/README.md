# usa2n — THE LITTLE LAB

淡いグリーンのレトロな実験室を巡る、スクロール連動の3D個人サイトです。
現在は計画の第1段階「入口 → 自己紹介」の2場面を実装しています。外装の開閉、画面の奥への移動、机の組み立て、逆スクロールでの再生に対応します。

## 起動・確認

```sh
cd site
npm ci
npm run dev
```

http://127.0.0.1:5173/ を開きます。`#about` から自己紹介の場面を直接開けます。

```sh
npm test
npm run build
npm run preview
```

本番相当の確認は http://127.0.0.1:5174/。配信対象は `dist/` です。

GitHub Pages用のビルドをローカル確認する場合は、以下を使います。

```sh
npm run build:pages
npm run preview -- --base=/web_usa2n/
```

確認URLは http://127.0.0.1:5174/web_usa2n/ です。通常の開発URLは変わりません。

## 構成

- `index.html`: セマンティックな本文・ナビゲーション・キャラクターの案内。名前と紹介文は仮。
- `src/styles.css`: 配色、余白、PC・スマートフォン・タブレットの構図。
- `src/main.js`: スクロールとHTMLの同期、章への移動、動きを減らす設定、描画障害時の表示。
- `src/scene.js`: Three.jsによる端末・作業机。外部3Dモデルや有料素材は使用せず、基本形状で制作。
- `src/scroll.js`: 前進・逆再生で同じ状態になる、カメラ・外装・表示タイミングの計算。

依存はThree.js、GSAP、開発用Viteのみ。バージョンはロックファイルで固定しています。JSを使わない環境でも本文とリンクを読めます。OSの演出軽減設定、ページ内の切り替え、WebGLの描画中断にも対応します。

## 画像と権利

うさぎ忍者はユーザーのオリジナルキャラクターです。この会話での使用許可に基づき、[公開スタンプ](https://store.line.me/stickershop/product/28191966/ja)の原画PNGをローカル配信しています。キャラクターの描き換え・AI生成・背景加工は行っていません。公開素材は240×240pxのため、案内役の小さな表示に使用しています。

最初に添付された5枚は雰囲気の参考です。現在の配信ファイルには含めていません。前のサイトの配信内容は `qa/previous-version.zip` に退避済みです。
